## 3. Recognition probe results (25 Oct)

Same 284 clips (263 INCLUDE + 21 YouTube), 93 words, chance ≈ 1 %. References for
SignCLIP came from other datasets (ISLRTC, Bridgeconn). On-screen text was OCR-checked
on every frame (198 blurred, 7 dropped). Cost US$3.81.

| Clips | System | Right | Wrong | Unsure |
|---|---|---|---|---|
| All words (n = 284) | Gemini 4 Argon | 105 (37 %) | 179 (63 %) | 0 |
| | SignCLIP best guess | 35 (12 %) | 249 (88 %) | 0 |
| | SignCLIP with cut-off | 0 | 0 | 284 (100 %) |
| 12 demo words (n = 47) | Gemini 4 Argon | 25 (53 %) | 22 (47 %) | 0 |
| | SignCLIP best guess | 2 (4 %) | 45 (96 %) | 0 |

- Gemini: hello 8/8, thank you 5/5, today 4/4, yes 2/2, no 2/2; doctor, tomorrow,
  morning, evening all wrong. 168 of its 179 wrong answers claimed ≥ 0.9 confidence;
  it never said "unsure". p50 5.4 s, p95 15.8 s per clip, ~US$0.013 per clip, online.
- SignCLIP: ~1.6 s per clip on the Mac, offline, free; designed for the user's own
  examples, which this cross-signer test did not use.
- Conclusion: Gemini reads strangers' signs ~3× better but is too slow, costs per sign
  and cannot abstain, so it is not safe to speak automatically. Useful as a helper to
  suggest or label signs. The deciding test (both systems on the presenter's own clips,
  12-word list) has not been run.

## 4. Decisions taken in this period

| Decision | Choice |
|---|---|
| Composer LLM | Groq (Cerebras is not free) |
| `ALLOWED_RECIPIENTS` | `contact_id=+E164` entries (e.g. `clinic`) |
| Core ML | FP16 with `computeUnits = .cpuAndGPU` |
| Booking words in drafts | Allowed only if the receptionist's caption said them |
| Captions after End | Kept as a read-only transcript |
| Bolna status webhook | Its own secret (`BOLNA_WEBHOOK_SECRET`), not the custom-LLM token |
| Sign Lab silence repeat | Off unless `--silence-repeat` (each repeat is a paid Sarvam line) |
| Agent lines label | "Ishara (voice)" in the app and the Mac bridge |
| Recognition probes | OpenAI probe dropped; one experiment: Gemini 4 Argon (video) vs SignCLIP on the same clips |
