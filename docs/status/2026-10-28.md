# Ishara: system state on 28 October 2026

A snapshot after the first real calls. What works, what ran for real and how, what is
pending, and the known issues. Earlier snapshot: [25 October](2026-10-25.md). The deploy
and the read-only Bolna checks before the calls: [go-live check](2026-10-28-live.md). Call
details: [voice record](../experiments/voice.md#runs). Commands and pass rules for every test
layer: [docs/TESTING.md](../TESTING.md).

```text
 sign video ──▶ app (simulator) ──▶ Heroku backend ──▶ Bolna ──▶ real phone call
   (camera)     on-device ASL        draft, brief,       voice,      founder answers
                model, chips         agent's brain       transcript  as the receptionist
                                                                     
 28 Oct: this whole chain passed for Live mode and all three Call-for-me flows.
 Not yet: the same on the iPhone's own camera (issue #72).
```

## 1. What exists (all on `main`)

| Part | State |
|---|---|
| Recognition (D8) | The public Kaggle ASL Signs 1st-place model runs in the app (LiteRT) and on the Mac. Full 250-way softmax; only **hello, thankyou, yes, no, now, please, tomorrow, wait** can become a chip or a "Did you mean …?" tile, at the provisional cut-offs (global 0.65, per word 0.45–0.6, margin 0.3) (#83). Morning is out: the model learned the one-handed form (see §3). The framing hint now also fires when a one-handed sign's hand leaves the picture as the sign ends (#94) |
| Live mode | Sign → chips → draft (Groq + validator, templates as fallback; the 25-word limit applies to LLM drafts only, #74) → SEND → Bolna speaks the exact text |
| Call for me (D9) | Brief from the signed or tapped chips → one approval → the agent calls. Attended: "One moment, please." and a YES / NO / WAIT card, or for an open "when?" question a TOMORROW / MORNING / NOW / WAIT card (#87). Unattended: a callback promise. The opening shows as the agent's caption once Bolna has said it, and an ask names the time actually offered, not a refused one (#93). The ask card keeps the camera visible (#95). Notes record a callback promised in any words (#85) |
| Backend on Heroku | Basic dyno, one uvicorn worker (`WEB_CONCURRENCY=1` and `--workers 1`, #82). Release v15 runs `main` up to #93 (deployed backend tree equals `main`'s `backend/` at that commit; only #95's test receptionist line came later) |
| Bolna agent | Matches `agent.json`, with the call summary on and speech before the welcome message ignored (#71). The account is on trial: it dials only verified numbers |
| Tests | Simulator UI tests made reliable (#70), call edge cases (#69), Call-for-me hardening (#64), public-clip Gate 2 (#66), in-app replay of real ASL clips (#68), sign video → spoken text for every flow, locally and against the deployed backend (#89, #90), one recognition test list for verify.sh and CI (#79) |
| Mac fallback | Runs end to end from clips (#56) and calibrates before dialling (#75) |
| Demo material | Script, slides, submission text, demo-day runbook (#55) |

The simulator's **scripted fake call** (the default with no backend: `DemoScript.swift`,

## 3. Recognition results since 25 October

- **Gate 2 on public clips** (#66): 142 public dictionary clips (110 signs from 6–10 sources
  per word, 32 negatives), Mac path and app path, landscape and portrait. Re-judged with the
  shipped bundle (#83): **0 wrong chips** on all four runs, correct chips 66 / 55 / 63 / 57 of
  110, 0 chips on the negatives. The cut-offs were fitted and scored on the same clips, so
  these numbers are optimistic; the iPhone clips decide the final values.
- Every confident wrong chip in that run was a word in the app's vocabulary that nobody
  rehearses (`can`, `hungry`, `time`), which is why only the rehearsed words chip now.
- **MORNING:** the shipped model learned the one-handed form (one flat hand rising from the
  belly to stand upright beside the face, no horizon arm). The two-handed dictionary form
  stays flat. Morning is out of the chip vocabulary until the iPhone test of the one-handed
  form ([issue #72](https://github.com/BishalJena/ishara/issues/72)); it can still be tapped.
- **Simulator parity:** real ASL clips replayed through the app's whole chain match the
  expected results (#68); the framing hint catches a one-handed HELLO read from a partial
  view (#94).
