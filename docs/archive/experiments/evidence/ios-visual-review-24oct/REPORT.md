## Consistent and good

- Screen flow matches WORKFLOW/board: Home → Get ready (checklist face / both hands / light, then 2 s rest with a countdown, Start enabled only when ready) → Signing → Speaking → Delivered → next turn.
- Pill colours are right: green Watching, yellow "Sign in progress" (black text), red "Can't see you". Chips: green with ✕, red "?" with ✕.
- Safety rules are visible: SEND disabled with no draft; the turn-3 wrong chip is removed with ✕ and the draft recomposes; the [?] never reaches the spoken sentence (`25…28`); not-delivered only re-sends on a tap, and the banner says so; Speaking swaps SEND for a big STOP; quick replies and Clear are hidden or disabled while speaking; End is always reachable and is a red capsule as on the board.
- Quick reply "Repeat" → "Sorry, could you please repeat that?" with a "Quick reply" badge, and SEND is still needed (`30-qr-repeat.jpg`).
- The status line is clear: Dialing… → Ringing… → In call · m:ss → Speaking · m:ss → Call ended. Connection lost shows "reconnecting…" and keeps End.
- The full flow at 1× and 0.5× gives the same states. The not-delivered → re-SEND path works.
- The iPhone 17e at default text fits every screen without scrolling. Dark mode is readable apart from the accent (F10). The pill, chips, SEND and STOP keep their colours in dark mode.
- VoiceOver labels exist for the important controls ("Send reply" with a hint, "End call", "Camera: …", chips: "Unsure sign. It will not be sent. Try again.").
