# Bolna graph agent for Path B

`agent.json` is the graph agent from [PLAN.md §3](../../PLAN.md#3-architecture). It is
generated by `app/bolna_agent.py` with a placeholder backend URL and checked by a test,
so the file and the builder cannot drift. Regenerate it after changing the builder:

```sh
cd backend
uv run python -m scripts.bolna_agent render > bolna/agent.json
```

Research for task V3, read on **23 October 2026** from the
[docs index](https://www.bolna.ai/docs/llms.txt). Labels:

- **Documented**: stated on the linked page.
- **Inferred**: follows from documented facts, not stated directly.
- **Unverified**: not documented, or the docs disagree; the V4 spike call must check it.

Nothing here has been run against the live API yet.

## The graph

```
            welcome message (DISCLOSURE, before any node)
                              │
                              ▼
          ┌────────── listen (start node, LLM) ◀──────────┐
          │  repeat_after_silence_seconds = 15            │ unconditional
          │  custom LLM: empty reply / holding line       │ (next receptionist turn)
          │                                               │
 event user_reply                                         │
          ▼                                               │
        speak (LLM, words to interrupt = 0) ──────────────┘
          │  prompt carries only {{ishara_call_id}}; the backend speaks the call's
          │  approved in-flight turn (event properties never reach a prompt)
          │  event user_reply ─▶ speak (a second SEND before the receptionist answers)
          │
 event end_call (from listen or speak)
          ▼
        goodbye (static GOODBYE, function_call end_call, no edges)
```

## Commands

All write commands refuse to run without `--yes`, and print only the new id.
Order: deploy the backend (V1/V2) → register the model → create the agent.

```sh
cd backend
uv run python -m scripts.bolna_agent render                 # no network
uv run python -m scripts.bolna_agent register-llm --yes     # needs PUBLIC_BASE_URL, BOLNA_API_KEY, CUSTOM_LLM_TOKEN
uv run python -m scripts.bolna_agent create --yes           # needs PUBLIC_BASE_URL, BOLNA_API_KEY, CUSTOM_LLM_TOKEN; then set BOLNA_AGENT_ID
uv run python -m scripts.bolna_agent update --yes           # also needs BOLNA_AGENT_ID
```

`create` and `update` set the agent's `webhook_url` to
`PUBLIC_BASE_URL/bolna/webhook/<BOLNA_WEBHOOK_SECRET>` (override with `--webhook-url`).
The backend refuses SEND until this webhook reports `in-progress` (or the
receptionist's first words arrive as a caption), so without it the first reply of a
call is refused. The URL holds a secret, so it is never printed and the committed
`agent.json` keeps `webhook_url: null`.

Re-run `update` after changing `GOODBYE` so Bolna re-renders the static audio.
